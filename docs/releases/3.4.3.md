# Eta 3.4.3

- 新增“子代理预算管理”，入口位于设置页 Subagent 相邻位置，统一适配 COUI 与 Miuix 分组样式。
- 可设置任务总时长、模型请求超时、无有效输出超时、模型调用次数、工具调用次数及并发数量；支持精确输入和恢复默认。
- 子代理模型请求及上下文压缩接入独立看门狗，连接心跳不再无限延长等待；重试与压缩计入模型调用预算。
- 超限后停止等待并保留已有结果；超过并发上限的任务排队执行。
- 修复失败、中断及历史会话恢复后子代理详情仍显示运行中，以及迟到进度重新激活动画的问题。
- 修复跨会话子代理登记与控制冲突。

正式 APK 使用发布证书签名，启用 R8 代码压缩、资源裁剪，仅包含 ARM64 原生库。

验证：112 项定向回归通过，Debug 构建通过；完整 Robolectric 原生运行时测试受本地 Linux ARM64 环境限制，完整检查交由 GitHub Actions。

限制：不响应中断的外部工具可能继续后台执行到自然结束，但不会继续阻塞父代理等待。预算设置在下一次主代理任务开始时生效，总运行时长硬上限包含暂停时间。
